# REGID MK X-3 GCS releases

Download the latest macOS and Windows builds from [Releases](https://github.com/PJBUMITech/regid-gcs-releases/releases).

- **macOS:** Apple Silicon (arm64), macOS 13 or later. Unzip the archive, then open `REGID MK X-3 GCS.app`. If Gatekeeper blocks the app, right-click it and choose Open.
- **Windows:** 64-bit installer (`win64.msi`). It includes the application runtime, so the PC does not need a separate Python install.

The optional `Start with GPU` launchers in the macOS zip choose a render mode. Herelink RTSP video on a Mac needs ffmpeg installed on that Mac (`brew install ffmpeg`).
